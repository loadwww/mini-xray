# 口试回顾（notes）

每个里程碑一关，过完把当关的**概念性**口试题和答案沉淀到这里，方便以后翻。

## 收什么、不收什么

- **收**：跨项目通用的概念——语言机制、构建原理、协议语义、设计判据
- **不收**：只对 minixray 有意义的细节（某函数的行号、某条配置字段、某次踩的路径坑）——那些在 `NOTES.md` 和提交信息里
- 答案写"要点 + 判据"，不写散文；忘的时候扫一眼能想起来就够了
